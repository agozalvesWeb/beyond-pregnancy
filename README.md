# Beyond Pregnancy

A static educational website for women athletes navigating pregnancy, postpartum recovery and return to sport.

## Contents
- `index.html` — homepage
- `pages/` — topic pages and interactive tools
- `css/style.css` — responsive visual design
- `js/` — navigation, Body Map, roadmap, journal, checklist and quiz interactions
- `images/hero/` — photographic hero and running-banner assets adapted from the supplied visual reference.
- `images/content/` — recovery-strength supporting image.
- `images/anatomy/female-anatomy.png` — transparent-background version of the supplied female anatomy reference, used beneath the interactive hotspot overlay.

## Run locally
Open `index.html` in a modern browser. No build tools, server, database or package installation are required.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to provide the public `github.io` address.

## Important
This website is an educational student project. It is not medical advice, diagnosis, treatment or medical clearance. Clinical content should be reviewed by a qualified healthcare professional before public use. Do not enter identifiable health information into the journal; it runs locally in the browser and does not save entries.
